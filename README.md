#Репозиторий JSON Syntax Highlighter
Описание
JSON Syntax Highlighter – это набор консольных утилит на 8 языках программирования для красивого и удобного просмотра JSON-данных с подсветкой синтаксиса. Программа читает JSON из файла или стандартного ввода и выводит его в терминал с цветовым выделением ключей, строк, чисел, логических значений и null.

Возможности
Подсветка синтаксиса с использованием ANSI-цветов – ключи (голубой/синий), строки (зелёный), числа (жёлтый/оранжевый), булевы (пурпурный), null (красный), скобки (серый).

Режимы отображения:

--pretty (по умолчанию) – форматированный вывод с отступами.

--compact – компактный вывод без лишних пробелов.

--minify – минифицированный JSON (без пробелов).

Работа с файлами и stdin – если файл не указан, данные читаются из stdin.

Сохранение результата в файл (опция --output).

Поиск и фильтрация – можно указать путь к ключу (например, --filter "user.address.city"), чтобы вывести только поддерево.

Валидация – проверка корректности JSON с выводом ошибок.

Выбор цветовой темы – светлая или тёмная (автоопределение по терминалу в некоторых реализациях).

Пейджинг – вывод через less для больших файлов (опционально).

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Зависимости	Команда запуска
Python	Python 3.8+ (colorama не обязателен)	python json_viewer.py [опции] [файл]
JavaScript	Node.js 14+ и npm install commander chalk	node json_viewer.js [опции] [файл]
TypeScript	Node.js + ts-node, commander, chalk	ts-node json_viewer.ts [опции] [файл]
Go	Go 1.18+ (без внешних зависимостей)	go run json_viewer.go [опции] [файл]
Java	JDK 11+ (без внешних библиотек)	javac JsonViewer.java && java JsonViewer [опции] [файл]
C#	.NET SDK 6.0+ (без внешних пакетов)	csc JsonViewer.cs && JsonViewer.exe [опции] [файл]
PHP	PHP 8.0+ (без расширений)	php json_viewer.php [опции] [файл]
Ruby	Ruby 2.7+ (без гемов)	ruby json_viewer.rb [опции] [файл]
Использование
text
json_viewer [опции] [файл]
Если файл не указан, читается из стандартного ввода.

Опции
Опция	Описание
-p, --pretty	Вывод с отступами (по умолчанию).
-c, --compact	Компактный вывод (без лишних пробелов).
-m, --minify	Минифицированный вывод (удалить все пробелы).
-o, --output <файл>	Сохранить результат в файл.
--colors	Включить цветной вывод (по умолчанию, если поддерживается).
--no-colors	Отключить цветной вывод.
--theme <светлая/тёмная>	Выбрать цветовую тему (по умолчанию определяется автоматически).
--filter <путь>	Вывести только указанную ветвь (например, user.address.city).
--page	Прогнать вывод через системный пейджер (например, less -R).
-h, --help	Показать справку.
Примеры
bash
# Простой просмотр с подсветкой
python json_viewer.py data.json

# Компактный вывод без цветов
node json_viewer.js --compact --no-colors data.json

# Чтение из stdin
cat data.json | go run json_viewer.go --pretty

# Сохранение результата в файл
php json_viewer.php data.json -o formatted.json

# Фильтрация по ключу
ruby json_viewer.rb --filter "user.address.city" data.json
Особенности реализаций
Все версии используют встроенные парсеры JSON (включая собственную реализацию для Java и C# при необходимости).

Цветная подсветка реализована через ANSI-коды, что делает вывод читаемым в большинстве современных терминалов.

Реализована обработка ошибок с указанием позиции синтаксической ошибки.

Поддержка Unicode (кириллица и другие символы).

В некоторых версиях добавлена автоматическая пагинация через less для длинных выводов.
